## assignment_2_598

CADENCE corner-selection starter with 30 maps from divided world 1, seeded random
teleport deployments, and a clearly marked function for students to replace with
their own heuristic.

- [Setup and assignment starter instructions](assignment_2_598/README.md)
- [Student ZIP](assignment_2_598.zip)
- [Student policy entry point](assignment_2_598/main_algo/corner_selection.py)

Python 3.10 or newer and Pillow are required. Compiled visibility generators for
macOS, Windows, and Linux are included, together with a Python fallback; students
do not need Rust or build tools. See the starter README for platform verification
details and the teleport model's assumptions.
